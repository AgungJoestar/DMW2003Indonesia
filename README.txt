TENTANG PATCH
------------
Patch ini menerjemahkan Digimon World 2003 ke Bahasa Indonesia.
Hanya Story dan Dialog NPC yang diterjemahkan.

Patcher tidak menyertakan game dan tidak menimpa file game asli.
Anda harus memiliki file Digimon World 2003 milik Anda sendiri.


CARA MENGGUNAKAN
----------------
1. Jalankan:
   DW2003_Indonesia_Patcher.exe

2. Klik "Pilih BIN..." lalu pilih file .BIN Digimon World 2003.

3. Klik:
   PATCH BAHASA INDONESIA

4. Tunggu sampai progress mencapai 100%.

5. Setelah selesai, patcher akan membuat folder:
   patched

   Di dalamnya akan tersedia:
   - <nama game> [Bahasa Indonesia].bin
   - <nama game> [Bahasa Indonesia].cue

6. Jalankan file .CUE hasil patch menggunakan emulator PlayStation,
   misalnya DuckStation.


PENTING
-------
- Sebaiknya buka game melalui file .CUE.
- File BIN/CUE asli tidak diubah oleh patcher.
- Jika hasil patch lama sudah ada, patcher akan meminta konfirmasi sebelum menimpanya.
- Jangan tutup patcher selama proses patch berlangsung.


KOMPATIBILITAS MOD
------------------
Patcher dirancang agar hanya mengganti data teks yang dikenali.

Jika sebuah teks sudah diubah oleh mod lain dan tidak cocok dengan teks
original maupun teks Bahasa Indonesia, patcher akan melewati teks tersebut
dan melaporkannya sebagai konflik.

Ini membantu mengurangi risiko perubahan dari mod lain tertimpa, tetapi
kompatibilitas dengan setiap mod pihak ketiga tidak dapat dijamin.


JIKA PATCH GAGAL
----------------
Pastikan:
- File yang dipilih adalah .BIN Digimon World 2003 yang kompatibel.
- File tidak sedang digunakan atau dikunci aplikasi lain.
- Drive memiliki ruang kosong yang cukup untuk membuat salinan BIN.
- Anda memiliki izin menulis ke folder tempat game berada.

Jika Windows menampilkan peringatan keamanan untuk aplikasi yang diunduh,
pastikan file patcher berasal dari sumber distribusi resmi proyek ini.


HASIL PATCH
-----------
Patcher membuat hasil di subfolder "patched" pada folder game Anda.

Contoh:

Digimon World 2003\
├── Digimon World 2003.bin
├── Digimon World 2003.cue
└── patched\
    ├── Digimon World 2003 [Bahasa Indonesia].bin
    └── Digimon World 2003 [Bahasa Indonesia].cue
